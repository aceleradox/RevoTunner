# 🎧 RevoTuner

**RevoTuner** é um app experimental em **Vue.js** inspirado em **Launchpads e controladores DJ**, permitindo remixar músicas do YouTube usando pads de tempo, automação e efeitos visuais simples.

Projeto focado em **experimentação, aprendizado e criatividade**, sem uso de bibliotecas pesadas de áudio.

---

## ✨ Funcionalidades

- ▶️ Player de músicas do **YouTube**
- 🎛️ **Launch Pad** com até **120 pads**
- ⏱️ Cada pad pula a música para um ponto específico do vídeo
- 🎨 Pads com **cores e luzes aleatórias ao clicar**
- ⚡ Sistema de **pads automáticos** (sequência configurável)
- 🔁 Disco giratório clicável para voltar a música ao início
- 🎚️ Interface inspirada em launchpads reais
- 💻 Totalmente em **Vue 3 + Vite**

---

## 🧩 Tecnologias

- **Vue.js 3**
- **Vite**
- **YouTube Iframe API**
- HTML5 / CSS3 / JavaScript
